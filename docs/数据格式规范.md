# 《渊下》数据格式规范 v1

> 目标：**5e 规则的文字版地牢肉鸽**（索拉斯塔 / 博德之门那种手感），单人主角，
> 单局从零开始，没有任何跨局数值成长。JSON 是唯一数据源，引擎只认这里的字段。
>
> 写数据时必须遵守本文。字段名用英文、内容用中文。所有 JSON 不允许注释与尾逗号。

---

## 0. 通用约定

| 约定 | 说明 |
| --- | --- |
| id | 小写英文 + 下划线，全局唯一 |
| 属性键 | `str` `dex` `con` `int` `wis` `cha` |
| 属性中文 | 力量 敏捷 体质 智力 感知 魅力 |
| 技能 id | 见 §1.2，共 18 项 |
| 伤害类型 | 挥砍 / 穿刺 / 钝击 / 火焰 / 冰霜 / 闪电 / 强酸 / 毒素 / 光耀 / 暗蚀 / 雷鸣 / 力场 / 心灵 |
| 骰子写法 | `"1d8"` `"2d6+3"` `"8d6"`，不带空格 |
| 豁免/检定 DC | 9~20 的整数 |

## 1. 规则常量（`data/rules.json`，已写好，勿改结构）

### 1.1 熟练加值
角色 1~4 级 +2，5~8 级 +3，9~10 级 +4。

### 1.2 技能表（18 项，id → 名称 → 关键属性）

| id | 名称 | 属性 | id | 名称 | 属性 |
| --- | --- | --- | --- | --- | --- |
| athletics | 运动 | str | arcana | 奥秘 | int |
| acrobatics | 杂技 | dex | history | 历史 | int |
| sleight_of_hand | 手上功夫 | dex | investigation | 调查 | int |
| stealth | 隐匿 | dex | nature | 自然 | int |
| animal_handling | 驯兽 | wis | religion | 宗教 | int |
| insight | 洞悉 | wis | deception | 欺骗 | cha |
| medicine | 医药 | wis | intimidation | 威吓 | cha |
| perception | 察觉 | wis | performance | 表演 | cha |
| survival | 生存 | wis | persuasion | 游说 | cha |

### 1.3 状态白名单（只能用这 12 个，id 固定）

| id | 名称 | 效果 |
| --- | --- | --- |
| poisoned | 中毒 | 攻击检定与属性检定具有劣势 |
| burning | 燃烧 | 每回合开始受 1d4 火焰伤害 |
| stunned | 眩晕 | 无法行动 |
| restrained | 束缚 | 无法行动，攻击它的检定有优势 |
| frightened | 恐惧 | 攻击检定具有劣势，不能主动靠近 |
| blinded | 目盲 | 攻击检定具有劣势，被攻击时有优势 |
| prone | 倒地 | 近战攻击它的检定有优势 |
| invisible | 隐形 | 攻击检定有优势，被攻击时有劣势 |
| blessed | 祝福 | 攻击检定与豁免 +1d4 |
| hasted | 加速 | 额外一次攻击，AC +2 |
| weakened | 虚弱 | 伤害减半（向下取整） |
| dying | 濒死 | 死亡豁免中 |

## 2. `data/spells.json`

```jsonc
{
  "spells": [
    {
      "id": "fire_bolt",
      "name": "火焰箭",
      "level": 0,                       // 0 = 戏法
      "classes": ["wizard", "sorcerer"],// 可用职业的 class id
      "school": "塑能",
      "action": "动作",                  // 动作 / 附赠动作 / 反应
      "range": "120 尺",
      "concentration": false,
      "kind": "spell_attack",            // 见下表
      "dice": "1d10",
      "dmgType": "火焰",
      "desc": "你向目标掷出一枚火焰弹。命中时造成 1d10 火焰伤害。",
      "upcast": null                     // 见「升环」
    },
    {
      "id": "fireball",
      "name": "火球术",
      "level": 3,
      "classes": ["wizard"],
      "school": "塑能",
      "action": "动作",
      "range": "150 尺",
      "concentration": false,
      "kind": "save",
      "targets": "all",                  // single（默认） / all
      "save": "dex",                     // 目标用什么属性豁免
      "half": true,                      // 成功时伤害减半
      "dice": "8d6",
      "dmgType": "火焰",
      "desc": "……",
      "upcast": { "per": "1d6" }         // 每高 1 环 +1d6
    }
  ]
}
```

### 2.1 `kind` 取值

| kind | 含义 | 必填字段 |
| --- | --- | --- |
| `spell_attack` | 法术攻击检定 vs AC | dice, dmgType |
| `save` | 目标豁免 | save, dice, half, dmgType, 可带 cond |
| `auto` | 无需检定必定命中（如魔法飞弹） | dice, darts（飞弹数）, dmgType |
| `heal` | 治疗 | dice |
| `buff` | 给自己加状态或临时生命 | cond 或 tempHp, 可带 mods |
| `debuff` | 给目标加状态（可带豁免） | cond, 可选 save |
| `utility` | 非战斗或纯叙事效果 | desc 里写清 |

可选字段：
- `cond`：`{ "id": "burning", "name": "燃烧", "turns": 2, "dice": "1d4" }`（id 必须来自 §1.3）
- `mods`：`{ "ac": 2, "hit": 1, "dmg": 2, "spellDmg": 2, "spellDc": 1 }`
- `tempHp`：整数
- `darts`：飞弹数（`auto` 专用）
- `addMain`：true 表示伤害/治疗再加上施法属性调整值
- `cleanse`：true 表示移除自身负面状态
- `condSelf`：给自己加的状态

### 2.2 升环（upcast）
- `{ "per": "1d6" }`：每比基础环阶高 1 环，伤害骰 +1d6
- `{ "per": "dart" }`：每高 1 环，飞弹/射线数 +1
- `{ "per": "tempHp:5" }`：每高 1 环，效果量 +5
- `null`：不可升环

### 2.3 高级效果键（引擎已支持，按需填）

| 键 | 值 | 含义 |
| --- | --- | --- |
| `mirror` | 整数 | 获得 N 层镜像：每次被命中消耗 1 层，该次命中改为未命中 |
| `disadvantageAgainst` | true | 攻击你的检定具有劣势（朦胧术） |
| `flight` | true | 获得飞行（免疫地面束缚类效果） |
| `extraAttack` | 整数 | 每回合额外攻击次数（加速术） |
| `nextAttackAdvantage` | true | 你下一次攻击检定具有优势（真实打击、引导箭） |
| `bonusDamageNext` | `{ "dice": "2d6", "type": "雷鸣", "cond": {"id":"prone","name":"倒地","turns":1} }` | 你下一次命中时附加的额外伤害（至圣斩、荆棘之击） |
| `mark` | `{ "dice": "1d6", "type": "挥砍" }` | 标记目标，你每次命中它都附加该伤害（猎人印记） |
| `aura` | `{ "dice": "3d8", "type": "光耀", "save": "wis", "half": true }` | 你每回合开始时对全体敌人结算一次（魂灵卫士） |
| `recurring` | `{ "dice": "1d8", "type": "力场" }` | 召唤物：你每回合开始时自动攻击一次（灵能武器） |
| `acSet` | `{ "base": 13, "addDex": true }` | 直接把 AC 设为该公式（法师护甲） |
| `cleanse` | true | 移除自身所有负面状态（次级复原） |
| `actionDenied` | true | 目标本回合无法行动（用于附赠动作的强控） |

> 带有 `mods` 的 `buff` 类法术默认持续到战斗结束；`turns` 字段可指定回合数。
> `concentration: true` 的法术同一时间只能有一个生效，新的会替换旧的。

## 3. `data/monsters.json`

```jsonc
{
  "monsters": [
    {
      "id": "goblin",
      "name": "哥布林",
      "act": 1,                    // 1~3 幕
      "rank": "normal",            // normal / elite / boss
      "size": "小型",
      "type": "类人",
      "ac": 15,
      "hp": 7,
      "attrs": { "str": 8, "dex": 14, "con": 10, "int": 10, "wis": 8, "cha": 8 },
      "saveProfs": ["dex"],        // 有豁免熟练的属性，可空数组
      "skills": { "stealth": 6 },  // 技能 id → 加值
      "resist": ["毒素"],          // 抗性，可空数组
      "immune": [],                // 免疫，可空数组
      "vuln": [],                  // 易伤，可空数组
      "attack": {
        "name": "弯刀",
        "bonus": 4,                // 攻击加值
        "dice": "1d6+2",
        "type": "挥砍",
        "verbs": ["挥刀砍来", "贴着地面刺出一刀", "尖叫着扑上来"]
      },
      "multiattack": 0,            // >0 表示一次行动攻击几次
      "traits": [                  // 特性，effect 见 §3.1
        { "id": "nimble_escape", "name": "灵敏逃脱", "desc": "每回合可以用附赠动作撤离。", "effect": "disengage" }
      ],
      "abilities": [               // 特殊能力，可空数组
        {
          "id": "acid_splash",
          "name": "酸液喷溅",
          "cooldown": 3,           // 每几回合可用一次
          "kind": "save",          // save / buff_self / debuff / heal_self / drain
          "save": "dex",
          "dc": 12,
          "dice": "2d4",
          "type": "强酸",
          "half": false,
          "cond": { "id": "poisoned", "name": "中毒", "turns": 2 },
          "flavor": "它鼓起腮帮，吐出一蓬黑色的酸液！"
        }
      ],
      "xp": 50,
      "gold": [3, 10],
      "flavor": "一句给玩家的描述，20~50 字，要有画面感，不要用'这是一只哥布林'这种废话。"
    }
  ]
}
```

### 3.1 trait 的 `effect` 关键字（只能从这里挑，或留空）

| effect | 含义 |
| --- | --- |
| `pack_tactics` | 同类相邻时攻击有优势（简化为：每有一个同类存活 +1 命中，最多 +2） |
| `relentless` | 每场战斗一次，被击倒时以 1 HP 站起 |
| `undead_fortitude` | 每场战斗一次，致命伤时 DC 5+伤害 的体质豁免，成功保留 1 HP |
| `regenerate` | 每回合回复最大生命的 5% |
| `magic_resistance` | 对抗法术的豁免有优势 |
| `damage_resist_all` | 受到的物理伤害 -3 |
| `turn_resistance` | 免疫恐惧与眩晕 |
| `incorporeal` | 非魔法武器命中 -2 |
| `pack_leader` | 同类攻击 +1 命中 |
| `ambusher` | 战斗第一回合攻击有优势 |

### 3.2 数值基线（很重要，必须落在这个区间里）

引擎还会再乘一次「幕 × 档位」的平衡系数（`maps.json → balance`），
所以你写的数值应该是**相对强度**，但要保证同一幕内的相对关系正确。

| 幕 | 档位 | AC | HP | 攻击加值 | 单次伤害 | XP |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | normal | 11~14 | 9~20 | +3~+5 | 1d6~1d8+2 | 40~70 |
| 1 | elite | 14~16 | 30~48 | +5~+6 | 1d8+3~2d6+3 | 150~260 |
| 1 | boss | 15~16 | 60~80 | +6 | 1d10+4 | 400~600 |
| 2 | normal | 12~15 | 18~32 | +4~+6 | 1d8+2~2d6+2 | 80~130 |
| 2 | elite | 15~17 | 50~75 | +6~+7 | 2d6+4 | 280~420 |
| 2 | boss | 16~17 | 90~120 | +7 | 2d6+5 | 800~1100 |
| 3 | normal | 13~16 | 28~46 | +5~+7 | 1d8+3~2d6+4 | 140~200 |
| 3 | elite | 16~18 | 70~100 | +7~+8 | 2d6+5~2d8+4 | 400~560 |
| 3 | boss | 17~18 | 130~170 | +8 | 2d10+6 | 1500~2000 |

### 3.3 必须覆盖的怪物（id 自定，名字可自创但要有 D&D 味）

- **第 1 幕 · 苔沼林地**（妖精与野兽）：哥布林、狼、恶狼首领、树精幼苗、巨蛛、蛛网蜘蛛、鸟妖 —— 至少 6 个 normal + 2 个 elite
- **第 2 幕 · 沉没矿坑**（亡灵与异怪）：骷髅、食尸鬼、幽魂、石像鬼、地精萨满、食人魔、锈蚀构造体 —— 至少 6 个 normal + 2 个 elite
- **第 3 幕 · 黑曜圣所**（邪教与恶魔）：邪教徒、恶魔猎犬、魅魔、骨魔、暗影、石魔像、狂信者 —— 至少 6 个 normal + 2 个 elite
- **Boss（各 1 个）**：第 1 幕「蛛后祭司」、第 2 幕「矿坑亡灵领主」、第 3 幕「黑曜大祭司」

## 4. `data/events.json`

```jsonc
{
  "events": [
    {
      "id": "ev_collapsed_bridge",
      "name": "断裂的石桥",
      "acts": [1, 2],                 // 可出现于哪些幕
      "text": "一段 60~120 字的场景描述。留出明确的抉择空间，不要替玩家做判断。",
      "options": [
        {
          "label": "贴着岩壁爬过去",
          "hint": "运动检定 DC 13",
          "check": { "skill": "athletics", "dc": 13 },
          "success": { "text": "成功时的叙事。", "effect": { "xp": 40 } },
          "failure": { "text": "失败时的叙事。", "effect": { "hp": -8 } }
        },
        {
          "label": "绕远路",
          "hint": "安全，但浪费时间",
          "effect": { "xp": 15, "heal": 5 },
          "text": "结果叙事。"
        },
        {
          "label": "砍下崖边的枯树搭一座便桥",
          "hint": "需要一把利器",
          "require": { "weapon": true },
          "outcomes": [
            { "p": 0.7, "text": "成功叙事。", "effect": { "gold": 40 } },
            { "p": 0.3, "text": "失败叙事。", "effect": { "hp": -10 } }
          ]
        }
      ]
    }
  ]
}
```

### 4.1 `check` 支持
- `{ "skill": "perception", "dc": 15 }` —— 技能检定（推荐，主力用法）
- `{ "attr": "int", "dc": 13 }` —— 纯属性检定

### 4.2 `require` 支持
`{ "gold": 60 }` `{ "potion": 1 }` `{ "level": 3 }` `{ "hpPct": 0.5 }` `{ "weapon": true }` `{ "spellSlots": 1 }`

### 4.3 `effect` 支持的键（只能用这些）

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `hp` | 整数 | 生命增减（负数就是受伤，最低留 1 点） |
| `hpPct` | 小数 | 按最大生命的比例增减，如 `-0.25` |
| `heal` | 整数或骰子字符串 | `20` 或 `"2d8+5"` |
| `healPct` | 小数 | 按比例回复 |
| `tempHp` | 整数 | 临时生命 |
| `gold` | 整数 | 金币增减 |
| `xp` | 整数 | 经验 |
| `item` | 字符串 | 随机装备，值为 `common` / `elite` / `boss` |
| `potion` | 整数 | 随机获得 N 瓶药剂 |
| `scroll` | 整数 | 随机获得 N 张卷轴 |
| `buff` | 对象 | 长休前持续的增益：`{ "id":"blessed", "name":"受祝福", "desc":"...", "mods": { "hit": 1 }, "turns": null }` |
| `curse` | 对象 | 同上但为负面 |
| `reveal` | true | 揭示整幕地图 |
| `fight` | `"elite"` 或 `"normal"` | 立刻打一场 |
| `rest_free` | true | 免费回复一次（视为一次短休，不消耗生命骰） |
| `slot_restore` | 整数 | 恢复 N 个最低环阶的法术位 |

### 4.4 写作要求
- 至少 **20 个事件**，其中第 1 幕可用 ≥ 8 个、第 2 幕 ≥ 7 个、第 3 幕 ≥ 6 个（可跨幕）。
- **每个事件至少有一个选项带技能检定**，技能要覆盖到不同属性（力量/敏捷/感知/智力/魅力都要有）。
- 选项要有真实的取舍：不是「检定成功给好东西 / 失败扣血」这种纯赌博，
  至少三分之一的选项应该让玩家在两种收益之间选（例如「拿走金币」vs「拿到线索但放弃金币」）。
- 叙事风格：第二人称，克制、具体、有感官细节，不要抒情，不要用「你感到…」这种空话开头。

## 5. `data/items.json`

```jsonc
{
  "weapons": [
    {
      "id": "longsword",
      "name": "长剑",
      "category": "martial",        // simple / martial
      "kind": "melee",              // melee / ranged
      "dice": "1d8",                // 单手伤害
      "versatile": "1d10",          // 双手持用时的伤害（没有就 null）
      "type": "挥砍",
      "properties": ["versatile"],  // 见 §5.1
      "price": 15,
      "verbs": ["挥动长剑", "斜劈下去", "长剑前刺", "横斩过去"]
    }
  ],
  "armors": [
    {
      "id": "chain_mail",
      "name": "锁子甲",
      "category": "heavy",          // light / medium / heavy / shield
      "base": 16,
      "dexCap": 0,                  // 敏捷加值上限；轻甲为 null（不限）

      "rarity": "rare",             // uncommon / rare / very_rare / legendary
      "slot": "weapon",             // weapon / armor / shield / trinket
      "base": "longsword",          // 基于哪件普通装备（trinket 可为 null）
      "bonus": { "hit": 1, "dmg": 1 },
      "mods": { "dmg": 2 },
      "extraDice": "2d6",
      "extraType": "火焰",
      "desc": "……",
      "flavor": "……"
    }
  ],
  "consumables": [
    {
      "id": "potion_healing",
      "name": "治疗药水",
      "kind": "potion",             // potion / scroll / misc
      "price": 50,
      "action": "动作",
      "effect": { "heal": "2d4+2" },
      "desc": "……"
    }
  ],
  "lootTables": {
    "normal":  [["common", 80], ["uncommon", 20]],
    "elite":   [["uncommon", 70], ["rare", 30]],
    "boss":    [["rare", 70], ["very_rare", 30]]
  }
}
```

### 5.1 武器属性白名单
`finesse`（灵巧，可用敏捷） `versatile`（双手） `two_handed`（必须双手） `light`（轻型）
`heavy`（重型，小型生物劣势） `reach`（触及） `thrown`（投掷） `loading`（装填） `ammunition`（弹药）

### 5.2 数量要求
- 武器 **14 件**（简易 6 + 军用 8，含远程 3 件）
- 护甲 **7 件**（轻甲 3 + 中甲 2 + 重甲 2）+ **盾牌 1~2 件**
- 魔法物品 **24 件**（uncommon 8 / rare 8 / very_rare 5 / legendary 3），要有明确的风味与规则效果
- 消耗品 **12 件**（治疗/解毒/增益药剂 6 + 卷轴 4 + 其他 2）
